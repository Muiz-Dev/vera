# 11 — Authentication Engine

Version: 0.1.0

---

# Overview

The Authentication Engine is the core component of Vera.

Its responsibility is to verify identities and issue secure credentials that allow authenticated access to protected resources.

Authentication answers one question:

> **Who are you?**

Authorization is handled separately.

---

# Goals

The Authentication Engine should provide:

* Secure authentication
* Stateless access tokens
* Session management
* Password management
* Email verification
* Password recovery
* Multi-provider authentication
* Extensible authentication methods

---

# Responsibilities

The Authentication Engine is responsible for:

* Registering developers
* Authenticating developers
* Authenticating application users
* Issuing access tokens
* Issuing refresh tokens
* Creating sessions
* Revoking sessions
* Password verification
* Password reset
* Email verification

It is **not** responsible for authorization.

# Token Strategy

Authentication issues two tokens.

## Access Token

Purpose

Access protected APIs.

Characteristics

* Short-lived
* Signed
* Stateless

Recommended lifetime

```text id="auth08"
15 minutes
```

---

## Refresh Token

Purpose

Obtain new access tokens.

Characteristics

* Long-lived
* Stored securely
* Rotated after use
* Revocable

Recommended lifetime

```text id="auth09"
30 days
```

# Failed Login Handling

Repeated authentication failures should trigger protective measures.

Future protections

* Temporary account lock
* Progressive delay
* Audit logging
* CAPTCHA (optional)
* Risk scoring

---

# Authentication Errors

Common responses

| Status | Meaning                 |
| ------ | ----------------------- |
| 400    | Invalid request         |
| 401    | Invalid credentials     |
| 403    | Email not verified      |
| 429    | Too many login attempts |

Responses should never reveal whether an email exists.

---

# Security Requirements

Authentication must:

* Use HTTPS
* Hash passwords
* Validate all input
* Rate limit login
* Rotate refresh tokens
* Record audit logs
* Support session revocation
