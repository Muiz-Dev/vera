# Overview

The Search Engine is Vera's centralized discovery platform responsible for locating, ranking, filtering, and retrieving structured and unstructured information across the entire ecosystem.

Unlike traditional database queries that rely on exact values, the Search Engine provides a unified search experience by combining:

* Full-text search
* Semantic search
* Metadata filtering
* Hybrid ranking
* Knowledge discovery
* AI-assisted retrieval

It serves as the primary discovery layer for users, AI systems, autonomous agents, and applications.

The Search Engine integrates tightly with the Knowledge Engine, Vector Engine, AI Context Engine, and AI Memory Engine to deliver accurate, relevant, and explainable search results.

# Architecture Decision Record (ADR-030)

**Decision:** Vera centralizes all discovery capabilities into a dedicated Search Engine that orchestrates keyword, semantic, and federated search across the platform.

**Context:** Individual services implementing their own search logic lead to inconsistent ranking, duplicated infrastructure, fragmented user experiences, and increased operational complexity.

**Decision Outcome:**

* Search is unified behind a single platform API.
* Hybrid search combines traditional indexing with semantic retrieval.
* Security filtering is applied before results are returned.
* Ranking is centralized and continuously optimizable.

**Consequences:**

* Users receive consistent search experiences across every Vera product.
* AI systems can retrieve authoritative information efficiently.
* Future search technologies can be introduced without modifying application services.
* Discovery becomes a reusable platform capability rather than an application-specific feature.

# Design Goals

The Search Engine serves as Vera's unified discovery platform, enabling intelligent, secure, and scalable retrieval of structured and unstructured information across the ecosystem.

Its architecture emphasizes hybrid retrieval, semantic understanding, low-latency ranking, federated discovery, explainable results, and seamless integration with the Knowledge Engine, Vector Engine, AI Memory Engine, AI Context Engine, AI Engine, and the broader Vera platform.
