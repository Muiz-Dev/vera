# Overview

The Threat Detection Engine is responsible for identifying, analyzing, correlating, classifying, and responding to malicious activities across the Vera platform in real time.

Unlike the Risk Engine, which estimates the probability of suspicious activity, the Threat Detection Engine focuses on identifying **known, emerging, and active security threats** by continuously analyzing authentication events, API traffic, user behavior, network activity, application telemetry, and infrastructure signals.

The Threat Detection Engine serves as Vera's Security Analytics layer, enabling rapid identification of attacks before they compromise users, organizations, or platform infrastructure.

It integrates with every major engine to create a unified, real-time security defense system.

# Core Principles

## Detection Before Response

Threats should be identified before defensive actions are taken.

Detection and response remain separate responsibilities.

---

## Continuous Monitoring

Threat analysis never stops.

Every authentication request, API call, event, and infrastructure signal contributes to security awareness.

---

## Correlation Over Isolation

A single suspicious event may be harmless.

Multiple related events across different systems may indicate an active attack.

---

## Explainable Detection

Every detected threat should include

* Detection reason
* Evidence
* Confidence
* Severity
* Recommended action

---

## Intelligence Driven

Threat detection combines

* Internal telemetry
* Historical activity
* Threat intelligence
* Behavioral analysis
* Machine learning (future)

# Architecture Decision Record (ADR-018)

**Decision:** Vera centralizes security event analysis within a dedicated Threat Detection Engine that continuously correlates telemetry from every platform component.

**Reason:** Modern attacks span multiple systems and rarely appear as isolated events. Centralized correlation enables faster detection, improved accuracy, reduced false positives, and coordinated automated responses.

**Consequences:**

* Security visibility is unified across the platform.
* Detection quality improves through cross-engine correlation.
* Threat intelligence becomes reusable across services.
* Future AI detection capabilities can be integrated without redesigning the security architecture.

---

# Design Goals

The Threat Detection Engine provides Vera's real-time security intelligence by continuously identifying, correlating, and classifying malicious activities across identities, devices, sessions, APIs, and infrastructure.

Its architecture emphasizes continuous monitoring, explainable detection, scalable event processing, automated response readiness, and seamless integration with the Risk Engine, Device Trust Engine, Authentication Engine, Fraud Detection Engine, Incident Engine, and the broader Vera security ecosystem.
