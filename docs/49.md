# Overview

The API Key Engine is responsible for securely creating, managing, rotating, validating, revoking, and auditing API Keys across the Vera platform.

API Keys provide machine-to-machine authentication for applications, backend services, CI/CD pipelines, automation tools, command-line utilities, and server-side integrations.

Unlike user authentication tokens, API Keys identify an **Application**, **Environment**, or **Service Account**, rather than an individual user.

The API Key Engine is designed to provide enterprise-grade security while remaining simple for developers to integrate.

# Core Principles

## API Keys Are Secrets

API Keys must always be treated as confidential credentials.

They must never be stored in plaintext after creation.

---

## Environment Isolation

Each Environment maintains independent API Keys.

```text id="apikey01"
Application

↓

Development Key

↓

Staging Key

↓

Production Key
```

A Development Key must never authenticate against Production resources.

---

## Least Privilege

Every API Key should only have the permissions it requires.

Avoid broad administrative access whenever possible.

---

## Immutable Identity

Each API Key receives a permanent identifier independent of its secret value.

```text id="apikey02"
key_01KABCXYZ987654321
```

---

## Rotatable

API Keys should be replaceable without interrupting application availability.

↓

↓

# Architecture Decision Record (ADR-009)

**Decision:** API Keys are stored only as cryptographic hashes, while the plaintext secret is revealed exactly once during creation.

**Reason:** Storing only hashed API Keys significantly reduces the impact of database compromise, aligns with modern security best practices, and enables secure validation without exposing sensitive credentials.

**Consequences:**

* Lost API Keys cannot be recovered and must be regenerated.
* Database breaches do not expose usable secrets.
* Key rotation becomes a standard operational practice.
* Validation remains efficient through indexed hash lookups.

# Design Goals

The API Key Engine provides Vera's machine authentication infrastructure by delivering secure, scalable, and auditable API credential management.

It enables applications, services, automation systems, and deployment pipelines to authenticate safely through cryptographically protected credentials while maintaining strong isolation, comprehensive lifecycle management, enterprise-grade security, and seamless integration with the broader Vera platform.
