# Overview

The Developer Engine is responsible for managing every developer identity within the Vera platform.

While the **User Engine** represents a person's identity, the **Developer Engine** represents that person's role as a software developer building applications on Vera.

Every developer is a user, but not every user is necessarily a developer.

The Developer Engine manages developer profiles, projects, organizations, applications, SDK usage, API quotas, development preferences, onboarding progress, and developer-specific metadata.

It serves as the central hub for the developer experience across the Vera ecosystem.

# Vision

The Developer Engine should become the complete workspace for every engineer using Vera.

Every application, API key, webhook, organization, and deployment should ultimately belong to a Developer.

---

# Core Principles

## User First

Every Developer must reference exactly one User.

```text
User

↓

Developer
```

---

## One Developer Profile

A user may only own one developer profile.

---

## Independent Layer

Developer information should never be stored inside the User Engine.

Identity belongs to User.

Development belongs to Developer.

---

## Organization Ready

Developers may belong to multiple organizations.

---

## Extensible

Developer profiles should support future products without requiring schema redesign.

# Architecture Decision Record (ADR-002)

**Decision:** The Developer entity is separated from the User entity.

**Reason:** A user represents a person's identity, while a developer represents their participation in the Vera platform. Separating these concepts allows Vera to support additional user types (administrators, auditors, billing contacts, end users, service accounts) without changing the identity model.

**Consequences:**

* Every Developer references exactly one User.
* User authentication remains independent of developer functionality.
* Future platform roles can be introduced without modifying the User Engine.
* Developer-specific data remains isolated from core identity records.

---

# Design Goals

The Developer Engine provides the foundation for the Vera developer ecosystem by managing developer profiles, ownership, onboarding, and activity.

It establishes a clear separation between personal identity and developer capabilities, allowing Vera to scale into a comprehensive platform for individuals, teams, enterprises, and future developer-focused services while maintaining a clean and extensible architecture.
