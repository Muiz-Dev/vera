# Overview

The Automation Engine is Vera's event-driven execution platform responsible for automatically performing actions across the ecosystem without requiring human intervention.

Unlike the **Workflow Engine**, which orchestrates complex multi-step processes, the Automation Engine specializes in **reactive automation**. It continuously listens for platform events and executes predefined actions based on configurable triggers, conditions, schedules, and rules.

The Automation Engine enables organizations to automate repetitive operational tasks while maintaining security, auditability, and governance.

Typical examples include:

* Send a welcome email after registration
* Archive inactive organizations
* Rotate API keys every 90 days
* Notify administrators of failed deployments
* Trigger AI agents after document uploads
* Generate invoices monthly
* Synchronize users with external systems
* Escalate overdue approval requests
* Execute backups after deployments

Automation definitions are reusable, versioned, observable, and independently deployable.

# Architecture Decision Record (ADR-023)

**Decision:** Vera adopts a centralized event-driven Automation Engine for executing reactive platform operations independently of application services.

**Context:** Embedding automation directly within services leads to duplicated logic, inconsistent behavior, and difficult maintenance. Centralized automation improves reuse, observability, governance, and operational agility.

**Decision Outcome:**

* Automations are declarative and versioned.
* Execution is triggered by events, schedules, APIs, or webhooks.
* Automation workers remain stateless.
* Every execution is observable and auditable.

**Consequences:**

* Organizations can automate platform behavior without modifying application code.
* Business operations become faster and more consistent.
* Failures are isolated and recoverable.
* New integrations can be added without changing core platform services.

# Design Goals

The Automation Engine provides Vera's reactive execution infrastructure by automatically responding to platform events, schedules, and external triggers with secure, scalable, and observable actions.

Its architecture emphasizes event-driven processing, operational resilience, distributed execution, auditability, and seamless integration with the Workflow Engine, Rules Engine, Policy Engine, Event Engine, AI Engine, Notification Engine, and every service requiring intelligent automation.
