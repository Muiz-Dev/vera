# Overview

The AI Context Engine is Vera's real-time context orchestration platform responsible for assembling, enriching, optimizing, securing, and delivering the precise context required by AI models and autonomous agents.

Unlike the **AI Memory Engine**, which stores long-term experiences, the AI Context Engine builds a **temporary working context** for each request.

Its primary responsibility is answering the question:

> **"What information does the AI need right now to complete this task accurately?"**

The engine dynamically gathers information from multiple sources, ranks relevance, removes redundant data, applies security policies, respects token budgets, and delivers an optimized context package to the AI Engine or AI Agent Engine.

# Design Philosophy

More context does not always produce better intelligence.

The best AI systems receive **the right context**, not **all available information**.

The Context Engine optimizes for relevance, freshness, security, and efficiency.

---

The AI Context Engine is responsible for

* Context assembly
* Context ranking
* Context compression
* Duplicate removal
* Security filtering
* Token optimization
* Context caching
* Context telemetry

The AI Context Engine is NOT responsible for

* Long-term memory
* Knowledge creation
* Model inference
* Workflow execution
* Authentication

# Architecture Decision Record (ADR-027)

**Decision:** Vera introduces a dedicated AI Context Engine to assemble temporary, task-specific context independently from long-term memory and structured knowledge.

**Context:** AI systems perform best when supplied with relevant, optimized, and secure context. Mixing context assembly directly into application code creates duplication, inconsistent behavior, and inefficient token usage.

**Decision Outcome:**

* Context assembly is centralized.
* Multiple information sources are unified into a single optimized package.
* Security filtering occurs before model execution.
* Token budgets are managed independently of applications.

**Consequences:**

* AI requests become more accurate and consistent.
* Token usage is optimized across providers.
* Organizations maintain control over sensitive information.
* Future retrieval and optimization techniques can evolve without changing application logic.

# Design Goals

The AI Context Engine serves as Vera's real-time cognitive assembly layer, delivering secure, relevant, and optimized working context for AI models and autonomous agents.

Its architecture emphasizes intelligent context composition, semantic relevance, token efficiency, security, observability, and seamless integration with the AI Engine, AI Agent Engine, AI Memory Engine, Knowledge Engine, Vector Engine, Workflow Engine, and the broader Vera intelligence ecosystem.
