# Overview

The Risk Engine is responsible for continuously assessing the security risk associated with every authentication request, API call, device interaction, session, and sensitive operation within the Vera platform.

Rather than relying on static security rules, the Risk Engine combines identity signals, device trust, behavioral analytics, threat intelligence, environmental context, historical activity, and organizational policies to calculate a dynamic risk score.

The calculated risk score is used by other engines to determine the appropriate security response, including allowing access, requiring Multi-Factor Authentication (MFA), limiting permissions, terminating sessions, or blocking requests entirely.

The Risk Engine serves as the decision intelligence layer for Vera's adaptive security architecture.

# Core Principles

## Risk Is Dynamic

Risk changes continuously.

A trusted user today may become high risk tomorrow because of new devices, unusual behavior, or emerging threats.

---

## Context Over Identity

Identity alone is insufficient.

Risk evaluation considers

* Device
* Network
* Geography
* Time
* Behavior
* Threat intelligence
* Organization policies

---

## Continuous Assessment

Risk should be evaluated

* During login
* During API requests
* During sensitive operations
* During session lifetime

---

## Explainable Decisions

Every calculated risk score should include an explanation describing the contributing factors.

---

## Security Without Friction

Low-risk activities should proceed normally.

High-risk activities should receive additional verification rather than immediate rejection whenever appropriate.

# Architecture Decision Record (ADR-017)

**Decision:** Vera centralizes all adaptive security decisions through a dedicated Risk Engine that continuously evaluates contextual signals instead of relying solely on authentication success.

**Reason:** Modern attacks frequently involve valid credentials. Evaluating device trust, behavior, geography, network reputation, and threat intelligence enables significantly stronger protection against account compromise while minimizing unnecessary friction for legitimate users.

**Consequences:**

* Authentication becomes context-aware.
* Security responses adapt automatically to changing risk.
* Low-risk users experience fewer interruptions.
* High-risk activity receives stronger verification or immediate protection.

---

# Design Goals

The Risk Engine provides Vera's adaptive security intelligence by continuously evaluating the contextual risk associated with identities, devices, sessions, networks, and authentication events.

Its architecture emphasizes real-time analysis, explainable decision-making, Zero Trust principles, scalable event processing, and seamless integration with the Device Trust Engine, Authentication Engine, Policy Engine, Threat Detection Engine, Fraud Detection Engine, and the broader Vera security platform.
